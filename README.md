# Модуль фиксации нарушений для бота MAX

Веб-интерфейс (Mini App) для автоматизации работы аудиторов и специалистов по охране труда, промышленной и пожарной безопасности.

## Функционал
* Выбор категории нарушения (ОТ, ПБ, ППБ) через удобную форму.
* Текстовый ввод описания инцидента.
* Прямая отправка данных в чат-бот мессенджера MAX для последующей обработки искусственным интеллектом.

## Стек технологий
* HTML5
* CSS3
* JavaScript (Vanilla JS)
